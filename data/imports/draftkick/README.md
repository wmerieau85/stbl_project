# Exports DraftKick

Déposer ici l'export CSV de DraftKick,
renommé au format `draftkick_<étape>_AAAA-MM-JJ.csv` :

- `draftkick_draft_2026-09-25.csv` pour la phase draft ;
- `draftkick_ros_2026-11-02.csv` pour le reste de saison.

L'import prend automatiquement le fichier le plus récent de l'étape active.
Les stats peuvent être en totaux ou par match (détection automatique).
Les fichiers CSV de ce dossier ne sont pas versionnés.
