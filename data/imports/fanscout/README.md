# Exports FanScout

Déposer ici l'export CSV de https://fanscout.pro/projections (bouton « Download CSV »),
renommé au format `fanscout_<étape>_AAAA-MM-JJ.csv` :

- `fanscout_draft_2026-09-25.csv` pour la phase draft ;
- `fanscout_ros_2026-11-02.csv` pour le reste de saison.

L'import prend automatiquement le fichier le plus récent de l'étape active.
Les stats peuvent être en totaux ou par match (détection automatique).
Les fichiers CSV de ce dossier ne sont pas versionnés.
